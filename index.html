Workflow

不是随便写文案，而是一条可检查的工作流

Agent 先判断素材是否能用，再生成内容；素材不可读时必须停止。

输入素材接收链接、正文、截图或本地文件。
读取验证确认真实读到标题、正文和图片。
方向判断判断是否符合账号定位和资料包价值。
历史查重检查相似度，避免重复创作。
角度生成基于素材和历史表现生成差异化方向。
初稿生产生成标题、正文、标签和配图建议。
质量检查审查主命题、数据、攻击性和行动落地。
文档交付写入飞书文档并回查是否成功。

Standards

公开稿质量规范

核心目标：让内容能面对半信半疑读者，而不是只强化同温层共识。

✓
主命题稳定标题和开头的核心判断必须能被正文证明，正文只证明“值得尝试”时，不得写成“必须”。
✓
数据有来源所有数字、比例、市场规模、趋势判断必须有来源、年份、地区或口径；无法确认就删除或定性化。
✓
降低攻击性删除贬低读者、羞辱失败者、道德审判、性别/关系攻击等表达，改成解释型表达。
✓
行动要落地实操建议必须具体到动作、示例和完成标准；方法过泛时补成 7 天行动表。
✓
保留边界必须承认不是每个人都适合创业、辞职或创作者路径，避免把变富写成道德绑架。

Manual

Agent 使用说明书

陌生人看完这段，就知道如何准备素材、如何触发、如何验收。

它是什么
这是一个内容初稿生产 Agent：把选题、素材、历史内容和账号知识库，整理成一篇经过质量检查、可继续人工打磨发布的小红书 / 公众号内容初稿。
省了什么人工
之前人工完成素材读取、提炼、判断、查重、写作和建档，单篇约 90–150 分钟；现在由 Agent 执行标准流程，单篇约 10–20 分钟。
输入什么
输入内容素材、账号方向、发布平台、历史内容数据和补充要求。素材可以是小红书链接、公众号链接、复制正文、截图或本地文件；链接打不开时必须改用正文、截图或文件。
如何触发 
请执行【内容初稿生产】流程。

素材：{粘贴正文 / 链接 / 文件路径}
账号方向：学习方法 / 学生成长 / 资料包转化
发布平台：小红书 / 公众号
历史内容：飞书历史内容库链接 / 暂无
补充要求：语气适合初中生家长，结尾引导领取资料包
如何验收
检查标题是否过猛、正文是否具体、数据是否有来源、是否存在攻击性表达、是否有配图建议和发布时间、是否完成发布前质量检查、是否写入飞书文档并回查。
何时人工介入
素材打不开、标题/正文/图片缺失、历史内容库无法访问、选题匹配不确定、查重相似度达到 60% 以上、内容涉及高风险领域，或修正后仍像个人宣言稿时，必须人工确认。
